# Airy Blue Sage (theme key: `softBeige`)

Third theme — **Ground sprout card** reference (cornflower blue + pale sage earth on cool gray milk).

| Use | Token | Hex |
|-----|--------|-----|
| App background | `background` | `#F2F3F5` |
| Cards / surfaces | `surface`, `markMuted`, `organic` | `#E1EDE5` |
| Elevated | `surfaceElevated` | `#FAFBFC` |
| Panels / tracks | `surfaceSecondary` | `#CFDFD4` |
| Body text, icons, buttons | `text`, `primary`, `icon`, `buttonBackground` | `#212121` |
| Secondary text | `textSecondary` | `#5C6560` |
| Sage accent | `secondaryGreen`, `markSecondary` | `#9FC4AD` |
| Stem & leaf outline | `cool` | `#5494F7` |
| Leaf fill | `markLine` | `#BBD3FB` |
| Border | `border` | `#D5DDE2` |
