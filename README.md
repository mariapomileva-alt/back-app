# Back

A rapid self-help app for the next minute. Built with Expo, React Native, and TypeScript.

## Run

```bash
npm install
npx expo start
```

Then open iOS Simulator, Android emulator, or Expo Go.

## Stage 1

Foundation only: design tokens, three themes, Home, Settings shell, and theme switching.

Exercise tools, session outcomes, history, and subscriptions are staged next.

## Scripts

- `npm run typecheck`
- `npm run lint`
