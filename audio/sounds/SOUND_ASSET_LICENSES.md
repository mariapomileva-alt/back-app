# Listen sound asset licenses

Bundled Listen loops are **in-house synthetic placeholders** generated by `scripts/generate-listen-sounds.py` until professionally mixed studio assets ship. Each file is a seamless ~45 s mono WAV (16-bit PCM @ 22050 Hz).
