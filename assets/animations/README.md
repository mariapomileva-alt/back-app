# Back animations

All approved animated WebP assets in one place.

- `listen/` — 8 sound scenes.
- `ground/` — 7 Feet & Body steps plus 3 additional Ground modes.
- `move/` — 8 movement states.

These files loop automatically. Render with `contentFit="contain"` and do not add a second scale, bounce or spring animation on top. When Reduce Motion is enabled, use the matching PNG from `../assets/<section>/stills/` instead.
